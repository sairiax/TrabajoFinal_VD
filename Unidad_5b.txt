Uso de variables de entorno y sesión
 El uso de variables de entorno hace las

aplicaciones más robustas y compatibles
 Por ejemplo, puedes definir en el sistema la
ruta en la que se almacenan los datos:
 PARO_DATA_PATH = "../Datos/“

 Y después leerla en la aplicación:
import os
PATH_DATOS = os.environ.get("PARO_DATA_PATH", "../Datos/")

Uso de variables de entorno y sesión
 Como se ha comentado el script se re-ejecuta

de en cada interacción
 Si no se gestiona el estado, la app no recuerda
la información de usuario
 Con st.sesión_state podemos guardar el valor
de variables entre ejecuciones
 Resulta útil para filtros, selecciones, resultados
intermedios, etc.

 Por ejemplo, si queremos guardar la provincia

seleccionada:

if "prov_code" not in st.session_state:
st.session_state["prov_code"] = "00“

Uso de variables de entorno y sesión
 Si no existe la variable usamos una por defecto
if "prov_code" not in st.session_state:
st.session_state["prov_code"] = prov_data["codigo"].iloc[0]

if clicked_code:

 Uno o varios scripts: app.py (streamlit_app.py) o lo

llamas como quieras
 Fichero requirements.txt: contiene todas las
dependencias, librerías necesarias para la ejecución
 Ficheros de datos

Depurar app
 Para depurar una app de streamlit con VS Code:
 Crea este fichero: .vscode/launch.json

{"version": "0.2.0",
"configurations": [ {
"name": "Debug Streamlit",
"type": "debugpy",
"request": "launch",
"module": "streamlit",
"args": ["run", "${file}", "--server.runOnSave=false"],
"console": "integratedTerminal",
"justMyCode": true}]
}
12

Depurar app
 Abre en VS Code el fichero principal de tu app
 Pon un breakpoint haciendo clic a la izquierda

del número de línea
 Ve a Run and Debug: using launch.json
 Se abrirá Streamlit en el navegador
 Interactúa con la app hasta que llegue a la
línea marcada
